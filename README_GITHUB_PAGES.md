# Dupla Exclusão — GitHub Pages v12

Publique o conteúdo desta pasta diretamente na raiz do repositório `dupla-exclusao-educacional`.

## Principais mudanças da v12
- 10 simulados livres e repetíveis para estudo.
- 10 questões sorteadas entre 15 de cada módulo e alternativas embaralhadas em toda tentativa.
- Premiação única por simulado, máximo de 5 figurinhas: 0–1=0, 2–3=1, 4–5=2, 6–7=3, 8–9=4, 10=5.
- Refazer um simulado nunca gera novas figurinhas após a primeira conclusão.
- Avaliação institucional de qualquer simulado por turma ou aluno específico, solicitada por Professor, Gestor ou Administrador.
- Resultado da avaliação solicitada é confidencial: professor solicitante, Gestor e Administrador.
- Pesquisa Inicial disponível desde o início.
- Pesquisa Final liberada somente por Professor, Gestor ou Administrador.
- Comparação Inicial × Final no dashboard institucional.
- Integração com Supabase e cache PWA v12.
